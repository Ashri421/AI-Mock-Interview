# AI Mock Interview System

## Project Overview
AI Mock Interview System is a web application that helps students practice interview questions online.

## Features
- User Login
- Admin Login
- Mock Interview Questions
- Candidate Dashboard
- Interview Report Generation
- PDF Report Download
- Excel Report Generation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## How to Run

1. Clone the repository

2. Install requirements

pip install -r requirements.txt

3. Run

python app.py

4. Open

http://127.0.0.1:5000
